# Вебмайстерня · Журнал сигналів

Навчальний сайт IT / Security. Перевір медіа й браузерні API на головній. Демонстраційна форма реєстрації відкривається на окремій сторінці.

## Запуск

У Windows розпакуй всю папку й відкрий `START-Windows.cmd`. Потрібен Python 3. Щоб зупинити локальний сервер, закрий його вікно.

1. Розпакуй ZIP повністю. `index.html`, `register.html`, `style.css`, `script.js` і папка `media` мають бути в одному корені.
2. Відкрий термінал у цій папці. Запусти `py -m http.server 8000 --bind 127.0.0.1`. Якщо Python доступний у терміналі як `python`, використовуй цю команду замість `py`.
3. Відкрий `http://localhost:8000/` у Chrome. Для API використовуй localhost або HTTPS.

## HTML і доступність

Поля форми мають підписи й текстові повідомлення про помилки. Стан поля доступний через `aria-invalid`, а підказка пов’язана з ним через `aria-describedby`. У режимі `prefers-reduced-motion` анімація вимикається. Статуси залишаються текстовими.

Для відео додано субтитри й текстову версію чотирьох кроків. Окремої озвученої аудіодескрипції до ролика немає. Перевірка охоплює зазначені критерії й не є повним аудитом відповідності AA. [WHATWG HTML](https://html.spec.whatwg.org/multipage/) · [WCAG 2.2](https://www.w3.org/TR/WCAG22/).

## Локальна перевірка

Під час відкриття `index.html` як файлу можна переглянути оформлення, форму та медіа. Щоб перевірити браузерні API, запусти сайт на localhost. Для геолокації можна задати тестові координати **50.45010°, 30.52340°** у Chrome DevTools → Sensors. Дозвіл `granted` означає, що сайт може надіслати запит на системне сповіщення. Показ банера залежить від браузера й налаштувань ОС. Для локального файлу сайт пояснює, як запустити перевірку системного банера через localhost. У Chrome DevTools демонстраційні координати можна задати вручну. Перед здачею ЛР № 7 перевір публічну адресу в окремому вікні та додай її до звіту.

## Що додати до звіту

- ЛР № 5. Файли проєкту, скріншот коду, скріншот сторінки з обома плеєрами й кнопками, відповіді на питання.
- ЛР № 6. Файли проєкту, скріншот коду, кадр сторінки з координатами й показаним системним сповіщенням, відповіді на питання. Дозвіл або текстовий статус на сторінці допомагають перевірити API, але для звіту потрібен кадр системного банера.
- ЛР № 7. Публічна адреса, скріншот сайту з адресним рядком, скріншот репозиторію з файлами та відповіді на питання.
