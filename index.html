Поки що немає записів.

    Основи вебу

    Розмітка задає зміст, стилі визначають вигляд, скрипт обробляє дії.

    З чого складається сторінка

    Відкрий код сторінки, щоб знайти ці три частини.

    • HTML задає заголовки, списки, посилання й поля.
    • CSS керує оформленням і макетом.
      • На вузькому екрані блоки стають в одну колонку.
      • Рамка показує, де зараз клавіатурний фокус.
    • JavaScript обробляє натискання кнопки та виводить відповідь.

    Три кроки перед введенням даних

    Для вправи підійде адреса user@example.test.

    1. Перевір адресу сторінки.
    2. З’ясуй, навіщо потрібні поля.
    3. Для навчання використовуй вигадані дані.
